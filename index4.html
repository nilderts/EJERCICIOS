Presentación del Programa

El Programa de Estudios de Desarrollo de Sistemas de Información forma profesionales técnicos especializados en el desarrollo de aplicaciones web, programación y tecnologías modernas.

Durante esta unidad didáctica los estudiantes aprenderán HTML, CSS, JavaScript, PHP y MySQL para construir aplicaciones web funcionales.
