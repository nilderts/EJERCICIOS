1. Presentación del programa

El Programa de Desarrollo de Sistemas de Información forma profesionales técnicos capaces de analizar, diseñar, construir y mantener soluciones informáticas orientadas a las necesidades de empresas, instituciones y organizaciones.

En la unidad didáctica de Desarrollo de Aplicaciones en Internet, los estudiantes aprenderán progresivamente a construir páginas y aplicaciones web utilizando tecnologías como HTML, CSS, JavaScript, PHP y MySQL.

HTML permite estructurar el contenido de una página web, mientras que otras tecnologías se encargan del diseño, la interacción y el procesamiento de datos.

2. Perfil del estudiante

El estudiante de esta carrera debe desarrollar pensamiento lógico, responsabilidad, capacidad de análisis y disposición para resolver problemas mediante herramientas tecnológicas.

Capacidades importantes

  • Analizar problemas de información en una organización.
  • Diseñar soluciones web funcionales.
  • Organizar contenido mediante HTML.
  • Aplicar buenas prácticas de desarrollo.
  • Trabajar colaborativamente en proyectos tecnológicos.

Actitudes esperadas

  1. Responsabilidad en el desarrollo de prácticas.
  2. Participación activa durante la sesión.
  3. Respeto por el trabajo de sus compañeros.
  4. Interés por mejorar su código.
  5. Pensamiento crítico frente a problemas web.

3. Tecnologías que aprenderemos

El desarrollo web se basa en la integración de diferentes tecnologías. Cada una cumple una función específica dentro de la construcción de una aplicación web.

Tecnologías del lado del cliente

  • HTML: organiza la estructura de la página.
  • CSS: permite aplicar diseño visual.
  • JavaScript: agrega interacción y dinamismo.

Tecnologías del lado del servidor

  • PHP: procesa información enviada desde formularios.
  • MySQL: almacena datos de manera organizada.

Proceso básico para crear una página web

  1. Crear una carpeta del proyecto.
  2. Crear el archivo index.html.
  3. Escribir la estructura básica de HTML.
  4. Agregar encabezados, párrafos, listas e imágenes.
  5. Guardar el archivo.
  6. Abrir la página en el navegador.
  7. Revisar errores y mejorar la organización del contenido.
